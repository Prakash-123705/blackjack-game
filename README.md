🃏 Blackjack Game (JavaScript)

A simple and interactive Blackjack (21) card game built using HTML, CSS, and JavaScript.
This project simulates the core mechanics of Blackjack, allowing users to draw cards, track scores, and determine win/loss conditions in real time.

🚀 Features

Start a new Blackjack game
Draw new cards dynamically
Automatic sum calculation
Win/Lose/Blackjack detection
Player chip display
Real-time DOM updates
Clean casino-style UI

🛠️ Technologies Used

HTML5 – Game structure and elements
CSS3 – Styling and casino-themed UI
JavaScript (ES6) – Game logic and state management

🎮 How to Play

Click START GAME to begin
Two random cards are drawn automatically
Click NEW CARD to draw another card

Rules:

🎯 21 → Blackjack (Win)
❌ Above 21 → Game Over
🔁 Below 21 → Option to draw again
🧠 Game Logic Overview

Face cards (J, Q, K) are treated as 10
Ace is treated as 11
Game state is controlled using:
isAlive
hasBlackJack
Cards and sum are updated dynamically using DOM manipulation

JavaScript functions and conditional logic
Arrays and objects in real use cases
DOM manipulation and event handling
State management in browser-based games
Building interactive frontend projects
